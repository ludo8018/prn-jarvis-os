## 📌 Featured Projects

### 1. LUDO — Food Delivery Application
A food delivery web application inspired by platforms like Swiggy and Zomato.

**Key Features:**
- Restaurant listings and menu management
- Add-to-cart functionality
- Order management
- Ludo mini-game
- Discount coupon rewards for users who win the game

**Technologies:** Java, Servlets, JSP, JDBC, MySQL, HTML, CSS, JavaScript

### 2. Real-Time Boarding Data in Railway Reservation
An IoT-based passenger counting system designed to display real-time passenger boarding information.

**Key Features:**
- Passenger entry and exit counting
- IR sensor integration
- Arduino-based passenger detection
- LCD display for passenger count
- Web dashboard for viewing boarding information

**Technologies:** Arduino Uno, IR Sensors, LCD, Python, Flask

### 3. Obstacle Avoiding Robo Car
An Arduino-based robotics project designed to detect obstacles and navigate around them automatically.

**Technologies:** Arduino Uno, Sensors, Embedded C
